CONTEXTO DEL PROYECTO
"Repelón Conecta" (nombre provisional): marketplace local web que conecta a los negocios del municipio de Repelón, Atlántico, Colombia, con los compradores del pueblo. Es únicamente un proyecto web, que debe verse y funcionar bien desde el navegador del celular y del computador.

STACK OBJETIVO
- Backend: Spring Boot (Java 21, Spring Web, Spring Security con JWT, Spring Data JPA), PostgreSQL, API REST documentada con OpenAPI/Swagger, migraciones con Flyway.
- Frontend: web responsive y mobile-first en React + Tailwind que consuma la API. Sin plantillas renderizadas en servidor (Thymeleaf).
- Fotos en Cloudinary o similar.

DISEÑO
- Fondo blanco (#FFFFFF), barras de navegación verdes (#16A34A), botones azules (#2563EB).
- Interfaz en español, precios en COP con formato $12.000.
- Botones grandes y pocos pasos para comprar.

ROLES Y FUNCIONES QUE QUEREMOS
Comprador: registro/login (celular o correo), inicio con categorías y negocios destacados, buscador y filtros (categoría, barrio/vereda, "abierto ahora"), perfil de negocio, carrito (un negocio por pedido), entrega a domicilio o recoger, métodos de pago (efectivo, Nequi/Daviplata/transferencia con confirmación manual), historial y estados de pedido (recibido, en preparación, en camino, entregado, cancelado), botón de WhatsApp con resumen del pedido.
Vendedor: registro de negocio (queda pendiente de aprobación), editar perfil/horario/abierto-cerrado, CRUD de productos (nombre, descripción, precio, foto, categoría, stock), pedidos entrantes con cambio de estado, resumen de ventas del día y la semana.
Administrador: aprobar o rechazar negocios, gestionar categorías y usuarios, métricas (negocios activos, pedidos, ventas totales).
Modelo de datos mínimo: usuarios, negocios, categorías, productos, pedidos, items_pedido, direcciones.
Seguridad: roles con permisos, validación de formularios, rutas protegidas.
