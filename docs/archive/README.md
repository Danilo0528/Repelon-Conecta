# Archivo histórico

Estos documentos se escribieron a mano antes de montar la documentación viva.
Se conservan como contexto histórico; **no son la fuente vigente** y no se
actualizan con cada cambio de código.

La fuente vigente es:

- `docs/generated/` para la referencia de API y el índice de especificaciones.
- Los tests de frontend y backend para las reglas de negocio.
- `docs/README.md` para saber cómo regenerar y verificar.
